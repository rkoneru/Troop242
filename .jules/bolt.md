## 2026-03-31 - Linear-Pass Glossary Search and Grouping Optimization
**Learning:** Performing multiple filters, mappings, unique-value set conversions, and sorting steps directly in the React render loop creates unnecessary GC pressure and computation overhead. This is especially true for list items that are repeatedly filtered per group/letter ($O(L \cdot N)$ where $L$ is unique letters and $N$ is glossary terms). Grouping and sorting inside a single-pass `useMemo` block completely avoids rendering lag and limits computation to a linear $O(N)$ pass only when the search query actually updates. Hoisting static animation configuration objects prevents recreation on every render cycle and ensures reference stability for component props.
**Action:** Always extract static objects (like Framer Motion config/variants) to the module scope and combine multi-stage list filtering/grouping operations into a singular, highly cohesive `useMemo` computation block.
