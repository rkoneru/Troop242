## 2026-03-21 - [Optimize Badges filtering & Framer Motion variants]
**Learning:** Re-evaluating large static data structures (like the 140+ badges array) on every component render or local interaction (such as toggling a category view) can introduce unnecessary CPU overhead. Wrapping such operations in `useMemo` avoids redundant execution. Additionally, rendering static objects (like Framer Motion config objects) directly inline or inside the component function triggers garbage collection and recreation overhead; hoisting them to module scope preserves reference stability.
**Action:** Always identify any filtering, sorting, or mapping logic over static datasets inside React components and wrap them with `useMemo`. Hoist Framer Motion transition or animation variant objects to the module scope (or declare them statically outside the component body).
