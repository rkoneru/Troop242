## 2026-03-31 - Icon-Only Carousel Control Accessibility
**Learning:** Icon-only navigation buttons in carousels/sliders (e.g., ChevronLeft / ChevronRight) lack accessible text for screen readers unless explicitly provided via `aria-label`.
**Action:** Always provide descriptive `aria-label` attributes (e.g., `aria-label="Previous fact"`, `aria-label="Next fact"`) on icon-only carousel/slider control buttons.
