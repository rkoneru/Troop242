## 2026-08-06 - Header Dropdown Accessibility
**Learning:** For desktop navigation dropdowns that trigger on hover, screen readers can completely miss the navigation context if they lack appropriate accessibility attributes. Specifically, providing explicit `aria-haspopup="true"`, `aria-expanded`, and `aria-controls` attributes on the toggle button is critical for accessibility. Additionally, adding an `onClick` handler with stable functional state updates and a matching `id` on the menu container ensures correct behavior for keyboard-only and screen reader users without requiring hover interactions.
**Action:** Always verify dropdown toggles and submenus contain correct `aria-expanded`, `aria-haspopup`, `aria-controls`, and `id` properties, and can be activated via click/space/enter keyboards.
