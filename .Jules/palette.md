## 2025-05-07 - [Keyboard Navigable Search Results]
**Learning:** Implementing the WAI-ARIA Combobox pattern with `aria-activedescendant` allows for seamless keyboard navigation through search results while maintaining focus on the input field.
**Action:** Use `aria-activedescendant` paired with a `.active` visual style for any dropdown or list-based search component to ensure screen reader compatibility and a polished "app-like" feel.
